# Models

Training artefacts land here. Checkpoints are **not** committed (see
`.gitignore`) — they are large and fully regenerated by the training scripts.

```
models/
  tfidf_logreg/  pipeline.joblib        fitted TF-IDF + Logistic Regression
                 config.json            hyper-parameters actually used
  lstm/          best.pt                best-validation-F1 checkpoint
                 final.pt               last-epoch checkpoint
                 vocab.json             vocabulary built from the training split
                 config.json
  bert/          best.pt                best-validation-F1 checkpoint (raw state dict)
                 best_hf/               same weights in HuggingFace format (used by src/predict.py)
                 config.json
```

What *is* committed is everything needed to interpret and reproduce a run:
the configs in `configs/`, and the metrics, confusion matrices, training
histories and predictions in `results/`.

Rebuild any of them with:

```bash
python -m src.tfidf.train_tfidf
python -m src.lstm.train_lstm
python -m src.bert.train_bert
```
